# Prompts

这个目录公开了做 HumanBench 用过的全部 prompt。

## 一句话

先用 GPT-6 Pro、**4 条消息**生成一个学术风原型（v0.2），然后在 Claude Code 里用 **237 条消息、约 8,600 字**，把它重做成现在的 meme 版并上线运营：7 种语言、约 4 万访客、1.27 万人答完。

## 各阶段

| 阶段 | 消息数 | 其中插话 |
|---|---|---|
| 一、从 GPT-6 Pro 原型重做成 meme 版 | 41 | 9 |
| 二、上线前冲刺：域名、分享卡、多语言 | 16 | 6 |
| 三、打磨：难度、分享卡精致度、各平台适配 | 29 | 6 |
| 四、上线后看数据：埋点、Jev 代打、繁体和法语 | 57 | 13 |
| 五、深夜：Jev 批量跳题、尝试海外破圈 | 22 | 0 |
| 六、第二天：扩题、人格配色、隐藏款、修 Bug | 30 | 13 |
| 七、按数据迭代：渠道策略、好友 PK、代码安全 | 31 | 10 |
| 八、复盘与开源 | 11 | 1 |
| **合计** | **237** | **58** |

“插话”是 Claude 正在干活时我中途追加的消息。第一天晚上和第二天上午，很多改动都是这样边看边说出来的。

## 怎么提取的

Claude Code 会把每次会话完整保存在本机（`~/.claude/projects/` 下的 `.jsonl` 文件）。即使对话中途被压缩过，原始记录也都在。这里从中取出了所有由我输入的消息，包括中途插话，去掉系统通知、子任务回报和 `/compact` 之类的命令，只做了最少的脱敏（一个个人链接）。

Claude 的回复没有收录。这里只放“人说了什么”，方便看清一个人怎么靠说话指挥 AI 把一个产品从原型做到上线、再按数据迭代。
