# 起点：GPT-6 Pro 生成的 v0.2 原型

项目不是从零开始的。第一步是在 ChatGPT 里用 **GPT-6 Pro** 做了一个学术风的原型「测测你的参数 / HumanBench v0.2」，打包成一个压缩包（`HumanBench_完整总包_v0.2.zip`，2026-09-26 16:13）。

## v0.2 里有什么

- 可直接打开的单文件版网页
- 528 道题的题库（另有 v0.1 的 384 道历史题库），答案与数据口径文档
- 《产品与测评设计》：两条轨道（能力测评 / 模型人格）不混成一个结论、六维核心自适应测评、事实优先的评分和置信报告、参数量与架构只做娱乐展示层、Artificial Analysis 百分位的实现路径、补足科学依据的试测路线
- 经典 AI 陷阱题与反向变式（strawberry、洗车、9.11 vs 9.9 等）、独立的“模型人格”测评、自定义 ID、模型发布式结果表、AA 参考柱状图、PNG 分享长图、JSON 答题记录导出
- 桌面 / 移动端 QA 截图和自动化测试结果

## 之后发生了什么

在 Claude Code 里拿到这个压缩包后（见 [02-claude-prompts.md](02-claude-prompts.md) 第 1–3 条），方向完全变了：

- 删掉“选择题目数量”，改成固定一局
- 从“严肃测评”变成“你来扮演 AI”的整活：经典翻车梗、奇葩多轮对话、深度思考流、口癖鉴定
- 很多题不再有标准答案，改成点评
- 评分、人格、分享卡、多语言、埋点等全部重写

v0.2 留下的主要是几个核心想法：测参数量、模型发布会式的结果页、经典陷阱题、模型人格。

## GPT-6 Pro 阶段的 prompt

ChatGPT 对话「设计参数测试App」，2026-09-26 14:34–16:12（当地时间），[分享链接](https://chatgpt.com/share/6abb2c6b-26c0-83e8-a335-3ed6c179cef2)。我一共发了 **4 条消息**；模型那边回复了 110 次（GPT-6 Pro 为主，部分由 GPT-5.6 Thinking 完成），调用了 78 次工具写代码、跑测试，最后交出上面那个压缩包。原文：

1. `09-26 14:34` 想到一个有意思的小app：  
  测测你的参数  
  就是模拟用户各种输入（为了meme可以是选择题+一部分填空啥的？）  
  来看你相当于什么参数的模型  
  告诉你在artificial index上排名是什么百分位
2. `09-26 14:36` 来吧 要混合了科学依据➕有梗 要有题库 要自适应 题库尽量多一些 就是咱测试也要有点科学依据 严肃活泼
3. `09-26 15:36` 1. 还有那些经典的ai测试题 什么strawberry几个r （再来一些陷阱题） 还有什么50米洗车开车去还是走路去（搜一下）  
  2. 最后弄个可分享的 填自己的id  
  然后带两个的东西 一个是他们模型发布经典的那个表格 你的模型和其他的模型还有分数  
  另一个就是AA的那个柱状图  
  还有你的参数  
  以及另一个 你是什么模型人格（这个需要专门的题目测试 比如豆包型人格）
4. `09-26 16:12` 不对 你把整体的完整包打包给我

然后我把压缩包拿到 Claude Code 里，第一句是“看下下载里头有个这个 HumanBench_完整总包_v0.2.zip”，第二句是“这个感觉不太行”。
