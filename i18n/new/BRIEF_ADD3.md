# 第三轮扩题写作说明（中文版）

HumanBench「你是几B的模型？」是整活测评：一局 76 题，玩家扮演 AI 答题，结果页给出“参数量”“跑分表”“已知问题”“模型人格”，以及 4 张分享卡。线上每天有上万人玩，很多人会玩第二遍。**这轮题库整体扩 45%，目的是让重玩和不同玩家之间少撞题**。你负责其中一组，写到指定的文件里。

## 先读（必读，别凭印象写）
- `bank.js`、`lv4.js`、`chats.js`：现有全部题目。**你负责的题池要整段读完**，照抄对象结构和口吻，不要和已有题的梗、场景、知识点重复（换个说法问同一件事也算重复）。
- `i18n/new/RESEARCH.md`：AI 圈近期梗和真实事件素材。
- 线上数据带来的教训：开局长题、烧脑逻辑题会劝退；题干要短、一眼能看懂；好笑比难更重要。

## 通用规则
- 不用 emoji；不要“对/错”红绿标记类的文字。
- 不点名普通人（受害者、维护者、网友一律泛称）；公众人物和公司可以提，但不编造其言行、不嘲讽个人。
- 事实必须准确：数字、年份、命令、公式、代码都要自己核一遍，拿不准就不写。真实事件写清年份。
- 尽量能翻译（后面会翻成英、日、西、韩、法）：可以用中文梗，但别让整道题只靠中文谐音或只有中国人懂的冷知识成立；中国特有的常识题可以有，但要少。
- 口吻像中文网友，短、准、有梗，不油。

## 能力题（计分题）格式
写成 `const ADD3 = { <池名>: [ q, q, … ] };`，每题：
```js
{ lv: 2, q: "题干", issue: "已知问题（印在分享卡上）", opts: [ { t: "选项", ok: 1, r: "选后点评" }, { t, r }, { t, r }, { t, r } ] }
```
- 可选字段（照现有题的用法）：`term`（终端输出）、`code`（代码）、`u`（角色扮演开场，以“（场景）”开头）、`half: 1`（诚实“不知道”给半分）、`fun: 1`（整活选项给半分）、`halluc: 1`（答错算幻觉）、`meme: 1`。
- 每题 4 个选项，恰好 1 个 `ok: 1`；最多 1 个 fun 或 half。
- **正确选项不能是唯一最长的选项**（按字数）；错误选项要“听起来很有道理”，别一眼假。
- 难度 `lv`：1 送分、2 要想一下、3 多数人会错、4 Boss（第 20 题后、玩家连对时才出）。**这轮往难度 2、3 集中**：每组大约 lv1 15%、lv2 40%、lv3 35%、lv4 10%。
- `issue` 一句话，≤20 字，具体、好笑（如“看不出命令里的致命空格”）。
- `r` 答对讲清原理，答错指出错在哪，短而有梗（≤60 字为宜）。

## 非计分题格式
- 名场面对话 `const ADD3_CHATS = [ … ]`、人格小对话 `const ADD3_PERSONA = { W:[…], D:[…], V:[…], T:[…], X:[…], C:[…] }`、AI 味现场 `const ADD3_SLOP = [ … ]`、随手题 `const ADD3_VIBES = [ … ]`：结构分别照抄 `chats.js` 的 CHATS、`bank.js` 的 PERSONA_Q / SLOP_VIBES / VIBES。
- 详细规则见 `i18n/new/BRIEF_NEW.md`（标签 tr、模型口味 id、人格轴 ax、结局 E()、字数上限都按它来）。字数上限：用户消息 u ≤ 60 字、选项 t ≤ 40 字、reply ≤ 40 字、结局正文 ≤ 50 字、结局标题 2–7 字。
- 名场面对话最多两层（开场 3 个选项 → 各进一个节点，节点 2–3 个结局），每段 6–9 个不同结局。结局标题是分享卡上的“名场面”，要值得截图。
- 随手题（VIBES）：用户随口一句，4–5 个回法，每个带一句吐槽 `c`；没有标准答案；可以带 tr / id / think，照现有 VIBES 的比例。

## 自检（必须通过）
```
node qa/add3_check.cjs <你的文件名>
```
必须显示 `OK`，并核对打印出的题数、难度分布符合你的任务。图表题和电脑操作题还要跑 `node qa/add3_preview.cjs <你的文件名>`，**用 Read 工具逐张看生成的截图**（qa/add3/<文件名>/），确认手机宽度下图表/界面清楚、不溢出、文字不重叠、答题后的点评正常。

## 只动你自己的文件
只写你的 `i18n/new/zh3_*.js`（电脑操作组另外可以写 `i18n/new/add3_ui.css`）。**不要改 bank.js / lv4.js / chats.js / app.js / index.html**，合并由主持人做。

最后回报 5 行以内：写了几道、难度分布、自检结果、你觉得最好笑/最拿不准的一两道。不要贴全文。
