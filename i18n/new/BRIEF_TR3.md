# 第三轮扩题：翻译 + 本地化 + 母语自审

HumanBench「你是几B的模型？」（玩家扮演 AI 答题的整活测评，线上有中文、英、日、西、韩、法版）这轮新增了一批中文题，在 `i18n/new/zh3_*.js`。把分给你的那几个文件翻成你负责的语言，写到 `i18n/new/<lang>3_<同名>.js`（例：zh3_traps.js → en3_traps.js），**变量名不变**（ADD3 / ADD3_CHARTS / ADD3_UIS / ADD3_CHATS / ADD3_PERSONA / ADD3_SLOP / ADD3_VIBES）。

## 先看
- 通用本地化规则：`i18n/BRIEF.md`（法语另看 `i18n/fr/BRIEF_FR.md`）。
- 你这门语言现有版本怎么处理同类内容：`i18n/<lang>/bank.js`、`lv4.js`、`chats.js`（语气、术语、货币、单位、模型口癖；豆包 → en/ja/es/fr 为 Siri、ko 为 Bixby）。**注意西语版的对话、人格题用拉美用语**，计分题现有的是西班牙设定——新计分题用中性西语、避免地区特有的税率/法规。
- 真实事件素材：`i18n/new/RESEARCH.md`。
- **英语版必须先读 `i18n/en/STYLE_EN.md`**（英文版刚按英语 AI 圈口味整体改过一遍：更短、更干、别解释笑点，数据显示英文玩家耐心最差）。其他语言也可以参考它的“短、别解释笑点”原则。

## 不能改
对象结构、题目/选项/节点的数量和顺序、`lv`、`ok`/`half`/`fun`/`halluc`/`meme` 标记、`term`/`code`/`u`/`ui`/`chart` 字段的有无和键名、节点名、`go`、`tr`、`ax`、`id`、`think` 的有无、`E(title, text, id)` 的第三个参数。模型 id（"Claude"、"豆包"、"GPT-5 系" 等）原样保留。
- 图表（ADD3_CHARTS）和界面（ADD3_UIS）：只翻 SVG/HTML 里的可见文字，坐标、数值、类名、`data-opt` 一律不动；译文太长会溢出，要控制长度。
- 命令、代码、正则、公式保持可运行且结果正确；代码里的中文注释/字符串要翻，报错信息用真实英文原文。

## 要做
- 地道、好笑，像母语网友写的，不要翻译腔；不用 emoji；字数和中文差不多紧凑（手机上看）。
- 中文谐音/网络梗换成当地等价说法，保持笑点和选项作用不变。
- 中国特有的事：保留事实，一句话交代清楚是中国的事（如 “China’s college entrance exam, the gaokao”），不要改成本地发生的事；中国特有的职场/财务规则换成通用说法，不编造法规。
- **计分题的正确选项不能是唯一最长的选项**（译完要重新数）。
- JS 字符串里别用裸的直双引号，用 “ ” 或 « » 或「」，撇号用 ’。

## 母语自审（交之前必须做）
像挑剔的母语编辑把译文逐句再读一遍：当地读者能一眼看懂吗？事实（年份、价格、法律、技术细节）对吗？笑点在当地成立吗？有没有对地区、性别、职业、群体的冒犯？计分题答案还正确吗？

## 自检
每个文件跑：`node qa/add3_check.cjs <lang>3_xxx.js --zh zh3_xxx.js`，必须 OK（结构与中文一致、无残留中文、能被 JS 解析）。有图表/界面的文件，另外用 `node qa/add3_preview.cjs <lang>3_xxx.js` 出图并用 Read 看一遍有没有溢出（预览用的是中文页面外壳，只看题目区域）。

最后回报 5 行以内：每个文件的自检结果、3–5 个本地化处理、需要主持人决定的地方。
